# Общий приказ

Игра vangosha — синхронная головоломка: одна команда двигает двух роботов на отдельных полях 4×4. Нужно впервые привести обоих к их целям одним и тем же ходом. Доступны пять уровней, отмена хода и перезапуск; управление — кнопки, стрелки или WASD.

Первые два уровня сохранены. Новые задачи: «Опора на стены» (синхронизация через препятствия), «Ложный короткий путь» (цель рядом, но спешить нельзя), «Финальная комбинация» (оба приёма вместе). После победы можно перейти к следующей задаче; любой уровень доступен в переключателе.

Текущий уровень и история команд сохраняются локально в браузере: после перезагрузки можно продолжить, включая отмену ходов после победы или проигрыша. «Заново» очищает историю текущей задачи; смена задачи начинает выбранную заново. Если localStorage недоступен или заполнен, игра работает без сохранения. Некорректные или несовместимые сохранения сбрасываются к старту задачи 02. Сохранения не синхронизируются между браузерами; предел — 10 000 команд.

[Играть в браузере](https://vangosha-maker.github.io/common-command/)

## Локальный запуск

Из корня репозитория запустите статический сервер с помощью Python 3:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Если Python доступен как `python3`, замените имя команды. Откройте http://127.0.0.1:4173/ . Остановка сервера — Ctrl+C. HTTP-сервер нужен для загрузки JavaScript-модулей; сборка и установка зависимостей не требуются.

## Тесты

С установленными Node.js и npm выполните из корня репозитория:

```sh
npm test
```

Команда из `package.json` запускает `node --test tests/*.test.js`: проверки движка, уровней и интерфейса. Отдельный `tests/browser-qa.mjs` в эту команду не входит.

Расширенный браузерный smoke для пяти задач и сохранений: `python tests/browser-qa.py`. Он использует уже установленный Python Playwright и Chromium по пути `/usr/bin/chromium`, сам поднимает временный локальный сервер на свободном порту и закрывает сервер и браузер после проверки. Скриншоты сохраняются в `/tmp/common-command-upgrade-*`. В `npm test` браузерный smoke не входит. Анализ решаемости ограничен максимум 256 парами позиций на задачу; кратчайшие решения пяти задач — 11, 19, 7, 15 и 16 команд.

## Файлы и публикация

`dist/` содержит готовую игру и исходный JavaScript. GitHub Pages публикует копию из `docs/` ветки `main`; при изменении игры обновляйте обе папки.
